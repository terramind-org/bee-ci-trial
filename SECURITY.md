# Security policy

## Supported versions

Security fixes are supported for the current 0.1.x release line.

## Report privately

Do not open a public issue, discussion, pull request, or commit containing a suspected vulnerability. On this repository, open the Security tab and choose **Report a vulnerability** to use GitHub private vulnerability reporting.

Include the affected component and version or commit, the impact, reproduction steps or a minimal proof of concept, relevant configuration, and any mitigation you identified. Do not include credentials, private data, or details that would expose another system.

## What to expect

Maintainers will review the private report, assess affected versions and impact, ask questions if needed, and coordinate a fix or mitigation. Timing depends on severity, reproducibility, and release work; this policy does not promise a response or fix within a set number of hours. Please keep details private while the report is assessed and a coordinated disclosure is prepared.
